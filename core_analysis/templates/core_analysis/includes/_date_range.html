{% comment %} Reusable date-range control for the Floorsheet tabs: a preset dropdown mapped to the NEPSE trading calendar (Sun–Fri sessions; Saturdays and holidays excluded server-side) plus Start/End date inputs that appear only for "Custom Range". Pass `prefix` (e.g. "fav", "sw", "hot", "nh", "conc") to namespace the element IDs per tab; the frontend (floorsheet-brokers.js) wires each prefix with the shared `dateRange()` controller. Presets apply on change; Custom applies on Analyze. Optional `hide_today` / `hide_week` drop the two shortest presets. A/D Radar uses them because a window that short cannot answer its question: one session is refused outright by the service, and five is below the 15-session minimum the model was ever tested on. Better to not offer a choice than to offer one that always returns a warning. {% endcomment %}
