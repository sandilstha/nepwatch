LIQUIDITY EVENTS · this script, this day How events are defined
An event is the single price level whose quantity changed by at least half of the script’s rolling top-5 baseline between two captures. ADD = quantity appeared, PULL = quantity left. A pull can be a fill or a cancel; the floorsheet, not the book, settles which. Seconds are the gap between captures, so speed is only as fine as the feed.
DAY OVERVIEW · every script captured
Spike = top-5 quantity divided by that script’s own rolling median (last 20 captures), so a number means the same for a thin and a liquid name. Click a row to replay it.
